
Two pointers is a technique used in algorithms where you have two indices (referred as pointers) that traverse a data structure in the same or opposite direction to solve a problem more efficiently.

Generally two pointers are used in the following situations

**Sorted input**: when the dataset is either already sorted or can be sorted like binary search

**Pairs of subarrays**: when the problem involves two or more elements, subarrays, or ranges instead of a single like two sum, merge sort

**Linked Lists (Slow-fast pointers)**: used to detect cycles, find the middle node or checking for a palindrome property
